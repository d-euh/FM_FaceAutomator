# Bundled player-name fonts

User-provided original font files, included without modification:

- `koverwatch.ttf` — Koverwatch Regular, the default.
- `BebasNeue.otf` — Bebas Neue Regular.
- `venus rising rg.ttf` — Venus Rising Regular.

Choose a file in **폴더 · 연결 → 이름 글꼴**. No system font installation is required.

The same settings tab includes **이름 색상 / 크기** with a local preview. The default is cream `#F2DE9B` at 30px with a dark outline and shadow. Names stay on one uppercase line and shrink to fit; requested sizes can be 12–48px. Save settings to use them for subsequent generations.

**굵게 (Bold)** is enabled by default. Toggle it beside the size control to embolden the selected font's colored glyphs while retaining the dark outline and shadow. The local preview updates immediately; save to apply it to subsequent generations.

**기본값으로 초기화**, beside the font selector, resets the font, color, size, and bold option together to Koverwatch / `#F2DE9B` / 30px / bold enabled. The preview updates; use **설정 저장** to persist the reset for subsequent generations.
