FM Face Automator v1.0
설치 방법 및 주의사항

[현재 팀 구분]
세이브 빌드 27.1.0+2505117은 세이브의 팀 레코드와 구단 참조로 판정합니다.
팀 구분을 위해 게임 실행이나 팀 조회 DLL을 기다리지 않습니다.
기존 작업 기록은 자동으로 갱신하며 자유계약 경유 시 이전 팀의 확인 근거를 보존합니다.
미검증 유형·상태·관계는 AI 호출 없이 보류합니다.
팀 조회 DLL 조회·설치·연결 확인은 제거했습니다. 미지원 빌드는 DLL로 우회하지 않고 보류합니다.
아래 DLL 설치 안내는 그래픽 새로고침에만 해당합니다.

[압축파일 구성]
  FMFaceAutomator-Setup-v1.0.exe : 설치 프로그램
  README.txt                   : 이 안내문

[지원 환경과 준비 사항]
1. Windows 10/11 x64, FM27 Steam 빌드 26620374가 지원 대상입니다.
   게임 연동 DLL은 검증된 게임 바이너리 해시도 확인합니다.
   다른 게임 버전·빌드의 정상 동작을 보장하지 않습니다.
2. 앱을 받는 사용자는 Python, Git, Inno Setup을 설치할 필요가 없습니다.
3. Codex CLI 설치와 ChatGPT 로그인이 별도로 필요합니다.
   공식 안내: https://developers.openai.com/codex/cli/
   npm으로 설치할 경우 Node.js LTS 설치 후 다음 명령을 실행합니다.
     npm install -g @openai/codex
   사용하는 계정과 Codex 환경에서 이미지 생성 도구를 사용할 수 있어야 합니다.
4. 사용할 선수 사진·페이스팩·유니폼 자료는 사용자가 준비합니다.
   배포 파일에는 해당 사진 자료나 로그인 정보가 들어 있지 않습니다.

[처음 설치]
1. ZIP을 완전히 풀고 FMFaceAutomator-Setup-v1.0.exe를 실행합니다.
2. 설치 경로를 확인합니다. 새 설치 기본값은 %LOCALAPPDATA%\Programs\FMFaceAutomator입니다.
   일반적인 위치는 C:\Users\사용자이름\AppData\Local\Programs\FMFaceAutomator입니다.
   설치 화면에서 D: 등 다른 위치로 바꿀 수 있으며, 기존 설치가 있으면 그 경로를 우선 사용합니다.
   앱이 설정·작업 기록을 저장할 수 있도록 쓰기 가능한 전용 폴더를 선택하세요.
3. 설치를 마치면 시작 메뉴와 선택한 바탕화면 바로가기로 실행할 수 있습니다.
4. 처음 실행할 때 경로 검색을 마치면 '폴더 · 연결' 창이 열립니다.
   세이브·기존 페이스팩·유니폼·생성 저장 위치를 확인하세요.
   찾지 못한 경로는 '선택'으로 지정합니다.
5. 'ChatGPT 로그인'으로 연결하고 '설정 저장'을 누릅니다.
6. '이적 감지 범위'를 정하고 저장한 뒤 '자동 생성 시작'을 누릅니다.
   처음에는 기준을 기록하며 이후 세이브 저장에서 이적을 감지합니다.
   이적 없이 생성하려면 '직접 생성'에서 선수를 선택합니다.

[선수단 구분 및 게임 새로고침 연결]
1. BepInEx 6 Unity IL2CPP win-x64 be.793 이상이 먼저 필요합니다.
   공식 배포: https://builds.bepinex.dev/projects/bepinex_be
   BepInEx 5·Mono·구형 pre.2는 대상이 아닙니다.
   이 설치 프로그램은 BepInEx를 자동 설치하거나 기존 로더를 교체하지 않습니다.
2. BepInEx 초기 구성을 위해 FM27을 한 번 실행한 뒤 완전히 종료합니다.
3. 설치 완료 화면에서 게임 그래픽 새로고침 DLL 설치를 선택하거나,
   시작 메뉴의 '게임 그래픽 새로고침 DLL 설치'를 실행합니다.
   설치 폴더의 install_live_refresh.bat로도 실행할 수 있습니다.
   게임을 찾지 못하면 Steam의 '설치된 파일 → 찾아보기'에서 연 폴더의 fm.exe를 선택합니다.
   쓰기 권한 오류가 나면 게임 폴더 권한을 확인하고 필요한 경우 DLL 설치 도구만 관리자 권한으로 실행합니다.
4. 그래픽 새로고침 DLL은 0.2.3입니다.
   게임을 다시 실행하고 앱에 연결한 동일한 세이브를 불러옵니다.
5. 홈의 '페이스온 새로고침'으로 실제 반영을 확인합니다.
   자동 반영은 버튼 오른쪽의 '생성 후 자동 새로고침'을 켜고 설정을 저장합니다.

[기존 사용자 업데이트]
1. 기존 앱과 도구를 종료합니다. DLL도 설치한다면 FM27도 종료합니다.
2. 새 Setup EXE를 실행하고 기존 FMFaceAutomator.exe가 있는 폴더를 선택합니다.
   이전 포터블 버전을 dist\FMFaceAutomator에서 썼다면 그 폴더를 선택하세요.
   설치 위치가 달라지면 별도 설정과 작업 기록을 사용하게 됩니다.
3. 프로그램 파일만 교체하며 config.json, state, workspaces, 기존 페이스팩,
   사용자 사진·유니폼과 관련 없는 파일은 삭제·덮어쓰지 않습니다.
4. 기존 프로그램 파일은 설치 폴더의 program-backups 아래에 백업합니다.
   백업하지 못하면 설치를 시작하지 않습니다.
5. 설치 후 기존 설정·대기열·생성 이미지가 유지됐는지 확인하세요.
   정상 확인 후 필요 없는 프로그램 백업은 직접 정리할 수 있습니다.
6. 게임 연동 DLL이 갱신된 경우 DLL 설치 도구도 다시 실행합니다.

[제거]
Windows의 '설치된 앱' 또는 시작 메뉴의 제거 항목을 사용합니다.
설치 프로그램이 등록한 프로그램 파일과 바로가기를 제거합니다.
사용자 설정·작업 기록·페이스팩·프로그램 백업은 기본적으로 남습니다.
게임 폴더에 설치한 DLL과 BepInEx도 자동으로 삭제하지 않습니다.
기존 자료를 지우려면 필요한 자료를 백업한 뒤 사용자가 직접 정리하세요.

[주의사항 및 문제 확인]
- 합성에는 사용 계정의 도구 사용량과 비용이 발생할 수 있습니다.
  기존 생성 결과와 참조 사진을 재사용하며 불필요한 재호출을 피하세요.
- 팀 분류는 게임 진행에 영향받지 않습니다. 세이브 파일을 쓰는 중에는 안정된 파일을 기다리며, 게임 내 새로고침도 게임 진행 중 대기할 수 있습니다.
- 선수단을 제한했을 때 팀 구분을 확인하지 못하면 임의로 추측해 AI를 호출하지 않습니다.
- 설치·업데이트·제거 전 앱과 도구를 종료하세요. 실행 중이면 먼저 닫으라는 안내가 나올 수 있습니다.
- 설치 EXE는 앱을 설치하는 파일입니다. 다운로드만으로 자동 실행되지 않습니다.
- 현재 빌드 구성에는 코드 서명이 설정되어 있지 않아 Windows에서 확인되지 않은 게시자로 표시될 수 있습니다.
  배포 출처를 확인한 파일만 사용하고, 신뢰할 수 없는 파일을 실행하거나 보안 기능을 끄지 마세요.
- 경로 오류·Codex 미설치·미로그인·DLL 연결 오류는 안내한 준비 사항부터 확인하세요.
- 문제 보고는 '폴더 · 연결 → 문제 해결 펼치기 → 문제 진단 저장' 또는
  설치 폴더의 export_diagnostics.bat로 JSON을 저장해 첨부하세요.
  진단에는 설정 경로와 작업 상태가 포함되며 사진·지시·인증 정보는 포함하지 않습니다.
- 새 배포본의 실제 Windows 설치·업데이트·제거 및 게임 동작 확인은
  자동 테스트나 모의 검증과 구분해야 합니다. 배포자가 안내한 검증 범위를 확인하세요.
