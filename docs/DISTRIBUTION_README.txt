FM Face Automator v1.0
사용 준비 · 설치 방법 및 주의사항 · 프로그램 사용법

FM27에서 이적한 선수의 유니폼을 바꾼 페이스온을 만드는 독립형 프로그램입니다.
세이브 저장 후 이적을 감지해 Codex CLI로 합성을 요청하고,
선수 ID 파일명의 350×350 PNG와 config.xml을 저장합니다.
FM Newgen Face Studio를 설치하거나 연결할 필요는 없습니다.

압축파일 구성
  FMFaceAutomator-Setup-v1.0.exe : 설치 프로그램
  README.txt                   : 이 안내문


1. 프로그램 사용을 위한 세팅

[지원 환경]
- Windows 10/11 x64에서 FM27 세이브 파일을 사용합니다.
- 세이브 읽기·선수단 구분은 27.1.0+2505117, 27.1.1+2511875에서 지원합니다.
  27.1.1은 제공된 패치 후 세이브의 구조·판정 비교로 호환을 확인했으며, 패치 후 게임 화면 대조는 미검증입니다.
  팀 구분을 위해 게임을 실행하거나 팀 조회 DLL을 설치할 필요는 없습니다.
  미지원 빌드나 확인할 수 없는 팀은 선수단 범위를 제한한 작업을 보류합니다.
- 프로그램 사용자는 Python, Git, Inno Setup을 설치할 필요가 없습니다.

[Codex 준비]
1) Codex CLI를 설치합니다.
   공식 안내: https://developers.openai.com/codex/cli/
   npm으로 설치하려면 Node.js LTS를 먼저 설치합니다.
   Node.js: https://nodejs.org/
   설치 후 새 명령 프롬프트(CMD)를 열어 다음 명령을 실행합니다.
     npm install -g @openai/codex
2) 사용하는 ChatGPT 계정과 Codex 환경에서 이미지 생성 도구를 사용할 수 있어야 합니다.
   CLI 설치만으로 이미지 생성 기능의 사용이 보장되지는 않습니다.
3) 앱 설치 후 '폴더 · 연결'에서 'ChatGPT 로그인'을 눌러 계정을 연결합니다.
   Codex 실행 파일은 자동 검색하며, 찾지 못하면 실제 codex.exe를 선택합니다.
   codex.cmd나 codex.bat를 선택하지 마세요.

[사진·유니폼 자료 준비]
- 기존 선수 사진이 있는 페이스팩과 합성에 사용할 유니폼 키트 자료를 준비합니다.
  압축된 자료는 먼저 풀고 사진·config.xml이 들어 있는 자료 폴더를 연결하세요.
- 유니폼은 2026/27 시즌을 사용합니다. 골키퍼는 골키퍼용 키트가 필요합니다.
- 실제 선수의 사진이나 키트가 없으면 가능한 경우 웹에서 찾아 사용하지만,
  참조 이미지를 확보하지 못하면 합성이 보류될 수 있습니다.
  실존하지 않는 생성선수의 얼굴을 다른 실존 선수로 대신하지 않습니다.
- 사진·유니폼 자료와 로그인 정보는 배포 ZIP에 포함하지 않습니다.


2. 설치방법

[처음 설치]
1) ZIP을 완전히 풀고 FMFaceAutomator-Setup-v1.0.exe를 실행합니다.
2) 설치 경로를 확인하고 설치를 진행합니다.
   새 설치 기본값은 %LOCALAPPDATA%\Programs\FMFaceAutomator입니다.
   다른 위치로 바꿔도 되며, 쓰기 가능한 전용 폴더를 선택하세요.
3) 설치 완료 후 시작 메뉴 또는 바탕화면 바로가기로 앱을 실행합니다.
4) 처음 실행하면 자동 경로 검색 후 '폴더 · 연결' 창이 열립니다.
   아래 항목을 확인하고, 잘못되거나 비어 있는 항목은 '선택'으로 지정합니다.

   연결할 세이브 파일
     감지할 FM27 세이브(.fm)를 선택합니다. 게임에서도 같은 파일에 저장하세요.
   기존 페이스팩 폴더
     원본 선수 사진이 있는 페이스팩 폴더를 선택합니다.
   유니폼 키트 폴더
     합성할 유니폼 이미지와 매핑 자료가 있는 폴더를 선택합니다.
   생성 페이스팩 저장 위치
     자동 지정은 graphics에 faces 폴더가 있으면 faces\Z_FMFaceAutomator,
     없으면 graphics 바로 아래 Z_FMFaceAutomator를 사용합니다.
     기존에 저장한 경로는 유지하며 폴더 이름만으로 인게임 최상위 적용을 보장하지는 않습니다.
     기존 사진·키트 자료 폴더와 구분해 새 폴더를 지정하세요.
   Codex 실행 파일
     자동으로 찾은 codex.exe 경로를 확인합니다.

5) 'ChatGPT 로그인'을 완료하고 '합성에 사용할 유니폼'을 선택합니다.
6) '이름 스타일'에서 글꼴·색상·크기·굵기를 확인합니다.
   '모든 선수에게 적용할 지시'는 공통 요청이 있을 때만 입력합니다.
7) '설정 저장'을 누릅니다. 이후에는 우측 상단 '폴더 · 연결'에서 변경할 수 있습니다.

[기존 사용자 업데이트]
1) 실행 중인 앱과 도구를 종료합니다.
2) 새 ZIP을 풀고 Setup EXE를 실행합니다.
3) 기존 FMFaceAutomator.exe가 있는 폴더에 설치합니다.
   설치 위치가 달라지면 별도 설정·작업 기록을 사용하게 됩니다.
4) 업데이트는 프로그램 파일을 백업한 뒤 교체하며 설정·작업 기록·페이스팩을 보존합니다.
   config.json, state, workspaces와 사용자 자료를 삭제해 초기화하지 마세요.
5) 설치 후 앱을 실행해 기존 설정과 작업 기록이 유지됐는지 확인합니다.
   설치 폴더의 program-backups에는 교체 전 프로그램 파일이 남습니다.


3. 프로그램 사용법

[이적을 감지해 자동 생성]
1) '이적 감지 범위' 탭에서 대상 구단·선수, 영입/방출 방향,
   이적 유형과 포함할 선수단(1군·리저브·유소년)을 정하고 '설정 저장'을 누릅니다.
2) '자동 생성 시작'을 누릅니다.
   기본 설정에서는 처음 읽을 때 기준만 기록하고, 이후 저장된 세이브와 비교합니다.
3) 게임을 진행하고 연결한 세이브 파일에 저장합니다.
   선택한 범위의 이적이 감지되면 작업 대기열에 추가되어 순서대로 생성합니다.
4) 영입은 새 등록 팀, 방출은 이전에 확인한 등록 팀을 기준으로 판정합니다.
   선수단 구분을 확인하지 못하면 추측해 생성하지 않고 보류합니다.
   팀 분류는 게임 진행에 영향받지 않지만 세이브 파일을 쓰는 중에는 기다릴 수 있습니다.

[이적 없이 직접 생성]
1) '직접 생성' 탭에서 '목록 불러오기'를 누릅니다.
2) 선수 이름 또는 ID로 검색하고 선수를 선택합니다.
3) 유니폼을 사용할 구단을 선택합니다. 기본값은 선수의 현재 소속팀입니다.
4) '참조사진(선택)'에서 원하는 선수 사진을 불러올 수 있습니다.
   지정하지 않으면 기존 페이스팩에서 사진을 찾습니다.
5) 필요한 경우 '이 작업에만 적용할 지시(선택)'를 입력합니다.
   예: 표정을 웃는 표정으로 변경해주세요.
6) '생성 요청'으로 등록합니다. 앱이 작업 중이 아니면 해당 요청을 바로 실행합니다.
   다른 선수의 사진이 생성 중이면 다음 요청은 대기열에 추가합니다.
   자동 생성이 실행 중이면 대기 작업도 순서대로 처리합니다. 자동 생성이 꺼져 있다면
   현재 작업이 끝난 후 '자동 생성 시작'을 눌러 남은 대기 작업을 실행할 수 있습니다.
   요청을 등록하는 짧은 동안과 ChatGPT 로그인 중에는 요청 버튼이 잠시 비활성화됩니다.

[생성 결과와 지시]
- 원본 사진이 있으면 얼굴 크기·위치·크롭·자세·배경·조명을 유지하고
  보이는 유니폼만 바꾸도록 요청합니다. 이미지 모델 특성상 완전한 일치는 보장되지 않습니다.
- 공통·개별 지시가 있으면 명시적으로 요청한 요소만 바꾸며, 충돌 시 개별 지시를 우선합니다.
- 영문 선수 이름은 앱에서 그립니다. 이름 스타일 변경은 다음 생성부터 적용됩니다.
- 결과는 지정한 저장 폴더의 선수ID.png와 config.xml에 반영됩니다.
  기존 생성 결과와 관련 없는 파일·매핑은 보존합니다.

[작업 대기열]
- 작업을 선택하면 하단에서 상태와 오류 설명을 확인할 수 있습니다.
- Ctrl/Shift로 여러 작업을 선택하고 '작업 메뉴'에서 선택 작업을 처리할 수 있습니다.
- '현재 작업 중단'은 진행 중인 작업을 중단합니다.
  '작업 종료 후 멈춤'은 현재 작업이 끝난 뒤 멈춥니다.
- 보류된 작업은 설명에 나온 원인을 해결한 뒤 선택 재시도 또는 '전체 재시도'를 사용합니다.
  반복 재시도 전에 사진·유니폼·로그인 상태를 먼저 확인하세요.
- 완료된 작업은 새 작업이 들어오면 대기열에서 자동으로 숨깁니다.
  생성 이미지와 작업·호출 기록은 유지됩니다.

[게임 안에서 페이스온 새로고침: 선택 기능]
이 기능은 저장된 PNG/XML을 게임에 반영하기 위한 별도 연동입니다.
팀 분류와 파일 생성에는 아래 DLL 설치가 필요하지 않습니다.

1) BepInEx 6 Unity IL2CPP win-x64 be.793 이상을 준비합니다.
   공식 배포: https://builds.bepinex.dev/projects/bepinex_be
   BepInEx 5·Mono·구형 pre.2는 대상이 아닙니다.
   앱 설치 프로그램은 BepInEx를 자동 설치하거나 기존 로더를 교체하지 않습니다.
2) BepInEx 초기 구성을 위해 게임을 한 번 실행한 뒤 FM27을 완전히 종료합니다.
3) 시작 메뉴의 '게임 그래픽 새로고침 DLL 설치' 또는
   설치 폴더의 install_live_refresh.bat를 실행합니다.
   게임을 못 찾으면 Steam의 '설치된 파일 → 찾아보기'에서 연 폴더의 fm.exe를 선택합니다.
4) 게임을 다시 실행하고 연결한 세이브를 불러옵니다.
5) 홈의 '페이스온 새로고침'으로 반영을 확인합니다.
   자동 반영을 원하면 오른쪽 '생성 후 자동 새로고침'을 켜고 설정을 저장합니다.

새로고침 DLL은 0.2.3이며 FM27 Steam 빌드 26620374와 검증된 바이너리 해시에 제한됩니다.
27.1.1 세이브 지원과 새로고침 DLL 지원은 별개이며, 패치 후 DLL 호환은 아직 미검증입니다.
게임 진행 중에는 새로고침이 대기할 수 있습니다. 파일 저장 성공과 게임 내 표시 반영은 별개입니다.


4. 문제 확인 및 주의사항

- 이미지 합성은 사용 계정의 도구 사용량을 소모하거나 비용이 발생할 수 있습니다.
  기존 생성 결과를 재사용하며, 이미지가 마음에 들지 않는다는 이유로 자동 재생성하지 않습니다.
- CMD 창이 보이지 않아도 합성은 진행됩니다. 진행 상태는 대기열과 작업 기록에서 확인하세요.
  ChatGPT 로그인 시에는 로그인용 창이 표시될 수 있습니다.
- 문제가 생기면 '폴더 · 연결 → 문제 해결 펼치기 → 문제 진단 저장'으로 JSON을 저장하세요.
  설치 폴더의 export_diagnostics.bat로도 저장할 수 있습니다.
  진단에는 설정 경로·작업 상태가 포함되며 사진·지시·인증 정보는 포함하지 않습니다.
- 제거는 Windows의 '설치된 앱'에서 진행합니다. 사용자 설정·작업 기록·페이스팩·백업과
  게임 폴더에 설치한 DLL·BepInEx는 자동 삭제하지 않습니다.
